# 👤 Passo C.5: Painel do Cliente e Login na Vitrine

> **Objetivo:** Fornecer um portal de autoatendimento ("Área do Cliente") acessível diretamente pelo botão **Log In** da página inicial, onde o cliente acompanha o status do seu servidor, vê o IP/porta atualizado em tempo real, executa comandos rápidos (iniciar/parar/reiniciar) e acessa seu console avançado sem precisar de suporte manual.

---

## 1. Por que ter o Painel do Cliente?
* **Zero atrito pós-venda:** O cliente não precisa esperar você mandar mensagem no WhatsApp para saber se o servidor está ligado ou qual é a porta.
* **Autoatendimento:** Se o servidor travar ou se o cliente quiser reiniciar para aplicar um mod, ele mesmo aperta **Reiniciar** no painel.
* **Endereço Transparente:** O painel sempre exibe o IP e a porta ativa (ex: `jogar.beehost.qd.je` ou o túnel ativo do Bore), com botão de cópia rápida.
* **Acesso Integrado ao Crafty:** Um botão de destaque que abre o Crafty Controller (porta 8443) já com a sessão ou credenciais do cliente.

---

## 3. Especificação das Rotas da API (Backend)

| Método | Endpoint | Função | Autenticação |
| :---: | :--- | :--- | :---: |
| `POST` | `/api/cliente/login` | Autentica e-mail + senha e retorna token de sessão | Pública |
| `GET` | `/api/cliente/servidor` | Retorna status, IP/porta ativa, consumo de RAM e plano | Token do Cliente |
| `POST` | `/api/cliente/servidor/comando` | Executa ação (`iniciar`, `parar`, `reiniciar`) | Token do Cliente |
| `POST` | `/api/cliente/servidor/config` | Atualiza propriedades básicas (`motd`, `maxPlayers`) | Token do Cliente |
